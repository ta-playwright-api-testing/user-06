# REPORT — API Testing

## Завдання 1 — GET Cities

Перевірено API:

- `GET /api/cities`
- `GET /api/city/1`

`GET /api/cities` повертає статус `200`, JSON-масив із 5 містами.
Перевірено наявність полів `id`, `name`, `latitude`, `longitude`.
Також перевірено наявність міста `Київ` з `id: 1`.

`GET /api/city/1` повертає місто з назвою `Київ`.

## Завдання 2 — POST Sign In

Перевірено:

- `POST /api/signin`

Дані для авторизації беруться з `.env`:

- `USER_EMAIL`
- `USER_PASSWORD`

При успішній авторизації перевіряються `accessToken`, `id` та `email`.

Також перевірено негативний сценарій з неправильним паролем. API повертає статус `>= 400`.

## Завдання 3 — PUT User Profile

Перевірено:

- `GET /api/user/{id}`
- `PUT /api/user/{id}`
- повторний `GET /api/user/{id}`

Спочатку через API отримується поточний профіль користувача.

Потім через `PUT /api/user/{id}` змінюється тільки номер телефону, а решта обов'язкових полів (`email`, `firstName`, `lastName`, `roleName`) передаються зі старого профілю.

Після `PUT` виконується повторний `GET`, і перевіряється, що телефон змінився на очікуване значення.

Після перевірки старий номер телефону обов'язково відновлюється через `finally`.

## Завдання 4 — API + UI

Телефон користувача спочатку змінюється через API за допомогою:

`PUT /api/user/{id}`

Після отримання `accessToken` через `POST /api/signin` сесія передається в браузер за допомогою `page.addInitScript()`.

У `localStorage` передаються дані авторизації:

- `accessToken`
- `id`
- `role`

Після цього відкривається профіль:

`/user/{id}/page`

Телефон з UI зчитується за локатором:

`.user-phone-data`

Отримане з UI значення порівнюється зі значенням, отриманим через API.

Після завершення тесту початковий номер телефону відновлюється через API у блоці `finally`.

## Використані API endpoints

| Метод | Endpoint | Призначення |
|---|---|---|
| GET | `/api/cities` | Отримання списку міст |
| GET | `/api/city/{id}` | Отримання міста за ID |
| POST | `/api/signin` | Авторизація |
| GET | `/api/user/{id}` | Отримання профілю |
| PUT | `/api/user/{id}` | Оновлення профілю |

## UI

Профіль відкривається за шляхом:

`/user/{id}/page`

Для перевірки телефону використовується:

`.user-phone-data`
